Objetivo de la tarea:
Desarrollar un Juez de Rimas en Python que, empleando únicamente expresiones regulares y
lógica propia, evalúe estrofas de cuatro versos y asigne una nota final entre 0 y 10.

Instrucciones:
Escribir en el archivo estrofas.txt la primera linea las palabras bonus deseadas, siempre separadas por un ", ". Si no se desean palabras bonus, dejar en blanco
Se debe separar obligatoriamente la linea de palabras bonus y la primera estrofa con un salto de linea.
Se debe separar cada estrofa con al menos un salto de linea.
Toda estrofa debe tener exactamente 4 lineas.
Las vocales acentuadas y sus pares no acentuados NO se consideran equivalentes; "á" se considera un caracter distinto a "a", por lo que casos como "caso" y "casó" no se considerarán rimas (1).
No se consideran símbolos ni dígitos para evaluar las rimas; se recomienda que en caso de tener un verso como "tangente de 45", se cambie a "tangente de cuarenta y cinco", ya que el código está programado para ignorar los dígitos (2).
